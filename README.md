# 材料长度与消耗计算



介绍：

导入某种材料的多个需要的长度，自动计算出需要多少根某种材料，可设置整根误差和切割损耗。





1、在导入模板中，按已有数据格式，填写需要长度和数量

![1777913211495](./preview/preview1.png)

2、在页面中设置材料名称、材料长度、切割损耗、预留误差。点击导入，选择自己修改后的导入模板文件

![1777913288315](./preview/preview2.png)

3、查看计算出的消耗

![1777913343217](./preview/preview3.png)
